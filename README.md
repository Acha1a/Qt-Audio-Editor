# Аудиоредактор на Qt + GStreamer

Десктопное приложение для обработки аудио, разработанное на C++ (Qt 6) с использованием медиафреймворка GStreamer.

## 🚀 Функционал
- Воспроизведение аудиофайлов различных форматов (MP3, WAV, FLAC, OGG и др.).
- Визуализация аудиосигнала в реальном времени (RMS-уровни).
- 10-полосный эквалайзер с возможностью сохранения результата.
- Вырезание и удаление фрагментов аудиофайла.
- Микширование (вставка одного аудиофайла в другой).
- Конвертация аудиоформатов.

## 🛠 Технические особенности (Highlights)
- **Интеграция C-API и C++**: Работа с GStreamer (C) внутри объектно-ориентированной среды Qt (C++). Ручное управление памятью (RAII, `gst_object_unref`).
- **Многопоточность**: Вынос `GMainLoop` GStreamer в отдельный поток (`std::thread`), чтобы не блокировать UI.
- **Безопасное обновление UI**: Использование `QMetaObject::invokeMethod` и `Qt::BlockingQueuedConnection` для передачи данных из потока GStreamer в главный поток Qt.
- **Асинхронность**: Тяжелые операции (конвертация, вырезка) выполняются в фоновом режиме через `QtConcurrent::run` и контролируются `QFutureWatcher`.

## ⚙️ Сборка проекта
Проект использует `qmake`.
1. Установите Qt (6.x), GStreamer (1.x) и MSYS2 (если работаете на Windows).
2. Откройте `AudioEditor.pro` в Qt Creator.
3. *Важно*: Проверьте пути к GStreamer в `.pro` файле (`INCLUDEPATH` и `LIBS`). Они могут отличаться в зависимости от места установки MSYS2 на вашей системе.
4. Соберите проект (qmake -> Build -> Run).
